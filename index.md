## About Me

I'm Winston, a data science student at the University of North Carolina at Charlotte focused on motorsport data systems. I comfortable with python for data analysis, backend work, and can leverage libraries such as Pandas, NumPy, Matplotlib, Statsmodels, GeoPandas. I am also able to work with R for rigorous statistical and spatial analysis, supported by Java experience in object-oriented development and GIS skills for geospatial data handling and visualization. I've applied data science methods to motorsport analytics including a project analyzing whether pit strategy during NASCAR stage cautions affects finishing position, using the full 2026 regular-season dataset.
